# 付费功能配置说明

## 已实现的功能

✅ **月付和年付订阅**
- 月付：`com.example.livesnap.pro.monthly` ($4.99/月)
- 年付：`com.example.livesnap.pro.yearly` (价格在 App Store Connect 配置)

✅ **购买资格持久化**
- 使用 iCloud Key-Value Store 存储购买状态
- 即使删除 app 重新安装，购买资格也不会丢失
- 支持跨设备同步（同一 Apple ID）

✅ **自动验证机制**
- 应用启动时自动验证订阅状态
- 应用进入前台时自动验证订阅状态
- 合并 StoreKit 和本地存储的购买记录，确保不会丢失

## 需要配置的内容

### 1. App Store Connect 配置

#### 1.1 创建订阅产品

1. 登录 [App Store Connect](https://appstoreconnect.apple.com)
2. 选择你的 App
3. 进入 **"功能"** → **"App 内购买项目"**
4. 点击 **"+"** 创建新的订阅组（如果还没有）

#### 1.2 创建月付订阅

- **订阅组名称**：Pro Subscription（或自定义）
- **产品 ID**：`com.example.livesnap.pro.monthly`
- **类型**：自动续订订阅
- **价格**：$4.99/月（或你所在地区的等价价格）
- **订阅时长**：1 个月
- **本地化信息**：
  - 显示名称：Monthly Pro
  - 描述：Unlock all Pro features with monthly subscription

#### 1.3 创建年付订阅

- **产品 ID**：`com.example.livesnap.pro.yearly`
- **类型**：自动续订订阅
- **价格**：建议设置为月付的 10-12 倍（例如 $49.99/年，相当于 $4.17/月）
- **订阅时长**：1 年
- **本地化信息**：
  - 显示名称：Yearly Pro
  - 描述：Unlock all Pro features with yearly subscription. Best value!

#### 1.4 订阅组配置

- 确保两个订阅在同一个订阅组中
- 设置订阅组显示顺序（建议年付在前，显示为"推荐"）
- 配置订阅组本地化信息

### 2. Xcode 项目配置

#### 2.1 启用 iCloud Key-Value Store

1. 在 Xcode 中选择项目
2. 选择 **Target** → **Signing & Capabilities**
3. 点击 **"+ Capability"**
4. 添加 **"iCloud"**
5. 勾选 **"Key-value storage"**

#### 2.2 配置 App ID

1. 登录 [Apple Developer Portal](https://developer.apple.com/account)
2. 进入 **Certificates, Identifiers & Profiles**
3. 选择你的 App ID
4. 确保启用了以下功能：
   - ✅ App Store Connect API
   - ✅ In-App Purchase
   - ✅ iCloud (Key-value storage)

### 3. StoreKit 配置文件（可选，用于本地测试）

#### 3.1 创建 StoreKit 配置文件

1. 在 Xcode 中，选择 **File** → **New** → **File**
2. 选择 **StoreKit Configuration File**
3. 命名为 `Products.storekit`
4. 添加两个订阅产品：
   - `com.example.livesnap.pro.monthly` - Auto-Renewable Subscription - $4.99/month
   - `com.example.livesnap.pro.yearly` - Auto-Renewable Subscription - $49.99/year

#### 3.2 使用 StoreKit 配置文件测试

1. 在 Xcode Scheme 编辑器中
2. 选择 **Run** → **Options**
3. 在 **StoreKit Configuration** 中选择你的 `Products.storekit` 文件
4. 这样可以在模拟器中测试购买流程，无需真实 App Store 环境

### 4. 代码中的产品 ID

代码中已配置的产品 ID：
- `com.example.livesnap.pro.monthly` - 月付订阅
- `com.example.livesnap.pro.yearly` - 年付订阅

**重要**：确保 App Store Connect 中的产品 ID 与代码中的完全一致！

### 5. 测试配置

#### 5.1 使用沙盒测试账户

1. 在 App Store Connect 中创建沙盒测试账户
2. 在设备上退出 App Store 账户
3. 在应用内购买时，系统会提示登录沙盒账户
4. 使用沙盒账户完成测试购买

#### 5.2 使用模拟购买功能

- 在 DEBUG 模式下，应用提供了"Simulate"按钮
- 可以模拟购买，数据会保存到 iCloud
- 用于快速测试功能，无需真实购买

### 6. 验证购买资格持久化

#### 6.1 测试步骤

1. 完成一次购买（真实或模拟）
2. 检查控制台日志，应该看到：
   ```
   💾 Saved purchased product IDs to iCloud: ["com.example.livesnap.pro.monthly"]
   ✅ Purchase successful: com.example.livesnap.pro.monthly, Pro status saved to iCloud
   ```
3. 完全删除 app
4. 重新安装 app
5. 打开 app，应该自动恢复 Pro 状态
6. 检查控制台日志，应该看到：
   ```
   ☁️ Loaded purchased product IDs from iCloud: ["com.example.livesnap.pro.monthly"]
   ✅ Using persisted purchase data from iCloud/UserDefaults
   ```

#### 6.2 跨设备测试

1. 在设备 A 上完成购买
2. 在设备 B 上（使用相同 Apple ID）安装 app
3. 打开 app，应该自动同步 Pro 状态

## 注意事项

1. **产品 ID 必须完全匹配**：App Store Connect 中的产品 ID 必须与代码中的完全一致
2. **首次提交审核前**：确保所有订阅产品都已创建并处于"准备提交"状态
3. **价格设置**：年付价格建议设置为月付的 10-12 倍，提供更好的价值
4. **订阅组**：确保月付和年付在同一个订阅组中，用户可以轻松切换
5. **iCloud 同步**：需要用户登录 iCloud 才能实现跨设备同步
6. **网络问题**：如果网络不可用，应用会保留本地购买记录，确保用户不会丢失资格

## 常见问题

**Q: 为什么购买后资格丢失了？**
A: 检查 iCloud 是否已启用，确保 `NSUbiquitousKeyValueStore` 正常工作。

**Q: 如何测试订阅过期？**
A: 在 StoreKit 配置文件中可以设置订阅时长，或使用沙盒账户测试。

**Q: 年付价格如何设置？**
A: 建议设置为 $49.99/年（相当于 $4.17/月），比月付节省约 17%。

**Q: 如何验证 iCloud 存储是否工作？**
A: 检查控制台日志中的 `💾 Saved purchased product IDs to iCloud` 和 `☁️ Loaded purchased product IDs from iCloud` 消息。
